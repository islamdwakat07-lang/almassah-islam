# المساح إسلام

تطبيق أندرويد واحد يجمع أدوات المساحة:

- **حاسب الكواشين:** يقرأ صور سند الملكية ويحوّل حصص كل مالك وورثته إلى متر مربع (`app/src/main/assets/index.html`).
- **الإفراز:** يقسم القطعة بين الشركاء من ملف DXF، مع الطرق المقترحة واقتطاع البلدية (`app/src/main/assets/ifraz/`).
  يأخذ الحصص مباشرة من حاسب الكواشين بزر «خذ الحصص من حاسب الكواشين».
- **حاسبة الجرف:** الحفر والطمم من ملفات DXF (`app/src/main/assets/jarf/`).

الشاشة الرئيسية: `app/src/main/assets/home.html`.

## تحميل التطبيق

افتح صفحة **Releases** وحمّل `almassah-islam.apk` ثم ثبّته على الهاتف.
يُبنى ملف جديد تلقائياً مع كل تعديل يُرفع إلى فرع `main`.
