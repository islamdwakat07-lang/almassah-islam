# AI Architect — المرحلة 1: الأرض والارتدادات

أداة داخل تطبيق المهندس إسلام (وتعمل أيضاً كصفحة ويب على الكمبيوتر).

## البنية
- `src/engine/` المحرك الهندسي (بدون واجهة): `geometry` المساحة والزوايا · `corners` قواعد الرؤوس · `setbacks` المنطقة الصالحة للبناء · `verify` المُحقِّق المستقل · `classify` تصنيف الأضلاع · `explain` الشرح المبسّط · `clip` العمليات المنطقية (polygon-clipping أساسي + Clipper2 احتياطي).
- `src/io/` ملفات DXF (قراءة/كتابة R12)، لصق الإحداثيات، ZIP، والحفظ حسب المنصة.
- `src/data/` نموذج المشروع (بنسخة مخطط وترقية)، العمليات، التراجع، التخزين، أنظمة البلديات.
- `src/ui/` الواجهة.

## الارتدادات
الإزاحة الموازية للداخل. الزوايا المحدّبة: تقاطع خطَّي الارتداد. الزوايا المقعّرة: Miter (افتراضي، بحد) أو Square أو Round (أقل بعد عن الحد).
هامش أمان 0.2 ملم، وكل نتيجة يفحصها المُحقِّق المستقل داخل المحرك (`zone.verified`).

## الأوامر
- `npm test` اختبارات المحرك وDXF (تشمل 3000 أرض عشوائية)
- `npm run build` يبني داخل `../app/src/main/assets/ai-architect`
- `python3 tests/fixtures/make_fixtures.py` يعيد توليد ملفات DXF الاختبارية (يحتاج ezdxf)
- `python3 e2e/e2e.py <مجلد البناء>` اختبار المتصفح الكامل (يحتاج playwright)
